# ⚽ 2D 平面足球对战游戏

一个基于 **TypeScript + Canvas** 的 2D 俯视角足球对战游戏，支持本地双人、三人和人机对战。

---

## 🎮 游戏模式

| 模式 | 说明 | 人数 |
|------|------|------|
| **双人对战** | 键盘 vs 键盘，经典 1v1 | 2人 |
| **三人对战** | 键盘+键盘 vs 鼠标，2v1 对抗 | 3人 |
| **人机对战** | 键盘 vs AI，单人练习 | 1人 |

---

## 🕹️ 操控方案

### 玩家 1（红队 🔴）
| 操作 | 按键 |
|------|------|
| 移动 | `W` `A` `S` `D` |
| 踢球 | `空格` |

### 玩家 2（蓝队 🔵）
| 操作 | 按键 |
|------|------|
| 移动 | `↑` `←` `↓` `→` |
| 踢球 | `Enter` |

### 玩家 3（三人模式 / 蓝队 🔵）
| 操作 | 方式 |
|------|------|
| 移动 | 鼠标移动（球员跟随鼠标） |
| 踢球 | 鼠标左键 |

### 通用
| 操作 | 按键 |
|------|------|
| 暂停 / 继续 | `P` |
| 返回菜单 | `ESC` |

## ✨ 游戏特色

### 角色类型（3种）
- **像素小人** — 经典像素风格，有头、身体、手臂和腿
- **圆形球员** — 简洁圆形 + 朝向箭头
- **机器人** — 金属方块身体、天线、青色电子眼

### 场景主题（2种）
- **经典草地** — 绿色草坪 + 白色线条
- **赛博朋克** — 深蓝底色 + 霓虹发光网格 + 荧光球

### 场地大小（3种）
- **小场** — 球员大，节奏紧凑
- **标准** — 经典尺寸
- **大场** — 球员小，场地宽广

### 可配置项
- 胜利分数：3分 / 5分 / 10分 / 无限
- 移动速度：慢 / 普 / 快 / 极快

---

## 🎯 游戏机制

- **自然带球** — 球员跑动碰到球自动推动，无需按键
- **主动踢球** — 按踢球键大力踢出，力度随跑动速度增加
- **接球** — 对方踢来的球碰到你自动接住，停在脚下
- **踢球特效** — 踢球时显示冲击波 + 散射粒子
- **进球特效** — 屏幕闪光 + 画面震动 + 队伍颜色发光
- **音效** — 踢球、进球、反弹均有合成音效

| 技术 | 用途 |

| TypeScript | 类型安全 |

## 📁 项目结构

```
football-game/
├── index.html                    # 入口页面
├── package.json                  # 项目配置
├── tsconfig.json                 # TypeScript 配置
├── vite.config.ts                # Vite 配置
├── src/
│   ├── main.ts                   # 入口文件
│   ├── styles/
│   │   └── style.css             # 全局样式
│   ├── types/
│   │   └── index.ts              # TypeScript 类型定义
│   └── game/
│       ├── constants.ts          # 游戏常量、颜色配置、场景配置
│       ├── Field.ts              # 场地绘制（经典/赛博风格）
│       ├── Player.ts             # 玩家类（3种角色渲染）
│       ├── Ball.ts               # 足球类（物理、旋转）
│       ├── Physics.ts            # 碰撞检测与响应
│       ├── InputManager.ts       # 键盘 + 鼠标输入管理
│       ├── ScoreManager.ts       # 计分与胜利判定
│       ├── SoundManager.ts       # Web Audio 音效
│       ├── AIController.ts       # AI 控制器
│       └── Game.ts               # 游戏主类（状态机、游戏循环）
```

## 📋 游戏流程

```
模式选择（双人/三人/AI）
    ↓
角色选择（每个玩家选角色外观）
    ↓
游戏设置（场景、场地大小、胜利分数、速度）
    ↓
开始游戏
    ↓
进球 → 闪光特效 → 重置 → 继续
    ↓
达到胜利分数 → 游戏结束 → 再来一局 / 返回菜单
```
