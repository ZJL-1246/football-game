# ⚽ 2D 平面足球对战游戏

## 游戏概述

一个简单有趣的 2D 平面足球对战游戏，两名玩家在同一屏幕上控制各自的球员，争夺足球并射门得分。

---

## 🎮 游戏玩法

- **模式**: 本地双人对战（同屏分控）
- **目标**: 将足球踢入对方球门，得分多者获胜
- **场地**: 俯视角矩形足球场，两端各有一个球门

## 📐 核心设计

### 1. 场地 (Field)
- 矩形场地，带边线、中线、中圈
- 两端球门区域（凹槽式或线段式）
- 背景色: 绿色草坪

### 2. 玩家 (Player)
- 圆形身体，两队不同颜色（红 / 蓝）
- 顶部三角箭头表示朝向（跟随移动方向旋转）
- 跑动时有颜色拖尾效果（速度越快拖尾越长）
- 移动速度固定，支持 8 方向
- 有踢球冷却时间（防止连续粘球）

### 3. 足球 (Ball)
- 黑白圆形
- 被踢后有速度衰减（摩擦力）
- 碰撞边界反弹
- 碰撞球员后根据角度弹开

### 4. 物理系统 (Physics)
- 圆形碰撞检测（球员-球、球员-球员、球-边界）
- 速度向量运算
- 摩擦力衰减

### 5. 得分系统
- 球进入对方球门 → 得 1 分
- 显示比分板
- 进球后重置场地，球回到中心
- 胜利分数可配置（3分/5分/10分/无限）
